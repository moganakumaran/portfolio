## Deliberate credibility decisions
- No EB-1A or immigration terminology appears in the public site.
- No self-declared rankings such as “top 1%” are used.
- Workshop reviewing is labeled at the workshop level rather than implied as main-conference reviewing.
- INDEA conference infrastructure is linked, but the site does not claim that the current conference page independently verifies the TPC appointment.
- The newer `contrastive-failure-embedding` GitHub artifact is shown as a separate technical artifact and is not represented as the code repository for the 2023 publication.
- DOI, publisher, co-author, and final venue metadata remain explicitly pending canonical verification rather than being inferred.
